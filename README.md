# Sigara Bırakma Tedavi Planlayıcı

Hekimler için sigara bırakma tedavisi klinik karar destek aracı: Fagerström testi, ilaç seçimi, doz planı, etkileşimler ve izlem takvimi.

Geliştiren: Uzm. Dr. Kübra İclal ONAT ÜTÜK

Bu araç klinik karar desteği içindir; son karar hekimindir.

İlaç adı sözlüğü, TİTCK Ruhsatlı Beşeri Tıbbi Ürünler Listesi'nden her pazartesi GitHub Actions ile otomatik güncellenir (`tools/update_titck.py`).
